# GALAXY ARCHIVE

중학교 2학년 과학 「우리은하를 이루는 천체」 단원에서 성운과 성단을 배운 뒤 해 보는 웹게임입니다 (Vite + Phaser 4).
학생은 하늘 지도에서 실제 천문 관측 사진 20장을 모으고, 생김새로 나누어 묶고, 도감에 등록합니다.
태블릿과 스마트폰의 가로 화면에서 터치로 하며, 서버나 로그인이 없습니다.

아직 GitHub 저장소와 배포 주소는 없습니다. 지금은 이 폴더에서 직접 실행해서 확인합니다.

## 학생은 이렇게 합니다

1. **모으기.** 하늘 지도에서 별자리를 눌러 구역을 열고, 하늘을 천천히 훑으며 천체를 찾아 카드로 모읍니다. 카드는 20장입니다. 본부 의뢰는 한 번에 하나씩 나오고, 의뢰 하나에 찾을 천체는 최대 세 개입니다.
2. **묶기.** 사진만 보고 생김새가 비슷한 카드끼리 묶습니다. 먼저 「구름 같은 것 / 별 무리」로 나누고, 이어서 성운(방출·반사·암흑)과 성단(산개·구상)을 나눕니다. 「판정」을 누르면 맞았는지 알려 주고, 틀리면 힌트가 나옵니다.
3. **도감 등록.** 묶은 카드를 한 장씩 도감에 올립니다. 이름, 별자리, 지구에서의 거리(광년)를 봅니다.
4. **결과.** 점수와 등급이 나옵니다. 여기서 「사진 출처」 화면을 열 수 있고, 「보너스 관측」으로 우리은하 밖의 은하와 용어 의뢰를 더 해 볼 수 있습니다. 보너스는 점수에 영향을 주지 않습니다.

학생에게 보이는 용어는 교과서 표기를 씁니다: 우리은하, 오리온대성운, 플레이아데스성단, 말머리성운, 방출 성운, 반사 성운, 암흑 성운, 산개 성단, 구상 성단.

## 실행

컴퓨터에 Node.js가 설치되어 있어야 합니다. 아래 명령은 이 폴더(`galaxy-scope`)에서 연 터미널에 한 줄씩 입력합니다.

```
npm install
npm run dev        # http://localhost:5173/
npm test           # vitest
npm run build      # dist/
npm run preview    # 만들어진 dist/를 열어 확인
```

`npm run dev -- --host`로 띄우면 같은 Wi-Fi의 태블릿에서 `Network:` 주소로 열 수 있습니다.
빌드는 상대 경로(`base: './'`)를 쓰므로 `dist/`를 어느 정적 호스팅에 올려도 사진과 그림을 찾습니다.

## 폴더

| 폴더 | 내용 |
|---|---|
| `src/logic/` | 규칙(묶기 판정, 점수, 의뢰, 저장 등). Phaser를 쓰지 않는 순수 함수라 테스트로 확인합니다 |
| `src/scenes/` | 장면(하늘 지도, 훑기, 묶기, 도감, 결과, 사진 출처) |
| `src/data/` | 자료: `objects.js` 천체 목록과 사진 출처, `zones.js` 별자리 구역, `copy.js` 학생에게 보이는 글 |
| `src/config/` | 화면 크기와 `balance.js`(점수와 속도 같은 수치) |
| `public/photos/` | 관측 사진 31장(필수 카드 20장 + 보너스 11장) |
| `public/art/` | 게임 그림(배경, 틀, 요원, 단추 등) |
| `tools/` | 사진 내려받기와 그림 생성 도구 |
| `tests/` | vitest 테스트 |
| `docs/superpowers/` | 설계와 구현 계획 |

## 사진 출처 원칙

관측 사진은 실제 천문 관측 사진만 씁니다. AI로 만든 이미지를 관측 사진으로 쓰지 않습니다.
사진마다 원문 페이지 주소, 크레딧, 라이선스, 확인한 날짜를 `src/data/objects.js`에 적습니다.
지금 사진은 ESO, NOIRLab, ESA/Hubble에서 가져온 것이고 라이선스는 CC BY 4.0입니다. 교실 기기에서 빨리 열리도록 긴 변 1024px 이하(JPEG 품질 78)로 줄였고, 화면에서는 카드 창에 맞게 잘라 보입니다. 줄이고 잘랐다는 사실도 함께 적혀 있습니다.
이 정보는 게임 안의 「사진 출처」 화면(결과 화면의 단추)에 그대로 나오고, 불러오기 화면과 하늘 지도에는 기관과 라이선스를 한 줄로 보입니다.

사진을 추가하거나 바꾸려면:

1. `src/data/objects.js`의 목록에 천체를 추가하거나, 기존 항목의 출처 주소(`sourceUrl`, `pageUrl`)와 크레딧을 원문 페이지를 보고 고칩니다.
2. `node tools/fetch-photos.mjs`를 실행합니다. 목록의 사진을 내려받아 `public/photos/<id>.jpg`로 줄여 저장합니다. 이미 있는 파일은 건너뛰므로, 사진을 바꿀 때는 먼저 그 파일을 지웁니다.

## 게임 그림 만들기

배경, 틀, 요원, 단추 같은 게임 그림은 OpenAI 이미지 생성 API로 만듭니다. 직접 그린 도형으로 대신하지 않습니다.
무엇을 만들지는 `tools/art-manifest.json`에 적혀 있고, 아래 명령으로 만듭니다.

```
node --env-file=.env tools/gen-art.mjs [파일이름 ...] [--force]
```

- 결과는 `public/art/`에 저장되고, 이미 있는 파일은 `--force` 없이는 건너뜁니다.
- API 키(`OPENAI_API_KEY`)와 모델 이름(`OPENAI_IMAGE_MODEL`)은 `.env`에만 둡니다. `.env`는 `.gitignore`에 들어 있고, 절대 커밋하지 않습니다.
- `.env`는 이 도구만 읽습니다. 게임 코드(`src/`)는 키를 쓰지 않고, 빌드한 `dist/`에도 키가 들어 있지 않습니다. `dist/`의 파일에서 `OPENAI`, `sk-`, `api.openai.com`을 찾아봐도 하나도 나오지 않습니다.
- 게임 실행과 배포에는 `.env`가 필요 없습니다.

## 진행 상황 저장

진행 상황(찾은 카드, 현재 단계, 묶기 배치, 틀린 횟수)은 그 기기 브라우저의 `localStorage`에만 저장됩니다(키 `galaxy-archive-save-v1`).
서버로 보내지 않으므로 다른 기기나 다른 브라우저에서는 이어지지 않고, 브라우저의 사이트 데이터를 지우면 사라집니다.
결과 화면의 「처음부터 다시」를 두 번 누르면 저장이 지워지고 새 판이 시작됩니다.
