# 별구름 수집가

게임 이름은 「별구름 수집가」입니다(별 = 별 무리, 구름 = 구름 같은 천체). 폴더와 저장 키, 문서에 남아 있는 GALAXY ARCHIVE는 개발할 때 쓰던 이름입니다.

중학교 2학년 과학 「우리은하를 이루는 천체」 단원에서 성운과 성단을 배운 뒤 해 보는 웹게임입니다 (Vite + Phaser 4).
학생은 밤마다 임무를 받아 하늘 지도에서 실제 천문 관측 사진 20장을 모으고, 생김새로 나누어 묶고, 도감에 등록합니다.
태블릿과 스마트폰의 가로 화면에서 터치로 하며, 서버나 로그인이 없습니다.

- 게임: https://nebula-trdoolee.vercel.app
- 선생님 안내: https://nebula-trdoolee.vercel.app/teacher.html
- 수업 슬라이드: https://nebula-trdoolee.vercel.app/lesson.html (게임을 한 뒤 교과서 282~285쪽으로 정리하는 10장. →·스페이스로 넘기고 F로 전체 화면)
- 묶기부터 시작하기: https://nebula-trdoolee.vercel.app/?skip=sort (카드 20장을 다 모은 판으로 건너뜁니다. 그 기기에서 하던 판은 지워지고, 촬영 별점과 동트기 전 완료는 0점으로 시작합니다. 링크는 선생님 안내 쪽의 「수업 활용」에만 있습니다)
- 저장소: https://github.com/mrdoolee/galaxy-scope (`main`에 push하면 Vercel 프로젝트 `galaxy-scope`가 자동으로 배포합니다)

## 학생은 이렇게 합니다

0. **첫 화면.** 주소를 열면 게임 제목과 그림이 있는 첫 화면이 나옵니다. 「관측 시작하기」(하던 판이 있으면 「이어서 관측하기」)를 누르면 전체 화면으로 바뀌고 화면이 가로로 잠긴 채 게임이 시작됩니다. 가로 잠금은 안드로이드 기기에서 되고, 아이폰은 브라우저에 전체 화면 기능이 없어 주소창이 남습니다(「홈 화면에 추가」로 열면 주소창 없이 열립니다). 어느 기기든 세로로 들면 「기기를 가로로 돌려 주세요」 덮개가 나오고, 덮개를 누르면 다시 전체 화면·가로로 돌아갑니다. 「선생님 안내」는 교사 안내 쪽(`teacher.html`)을 엽니다. 하던 판이 있으면 「처음부터 다시 하기」도 보입니다. 두 번 눌러야(한 번 누르면 「한 번 더 누르면 처음부터」로 바뀌고 3초 뒤 되돌아갑니다) 저장을 지우고 새 판으로 시작합니다.
1. **시작 브리핑.** 새 판을 처음 열면 본부 요원이 인사하고 할 일을 알려 줍니다. 밤마다 임무를 받는다는 것, 별자리의 밝은 별이 길잡이라는 것, 해가 뜨기 전에 마치면 좋다는 것, 망원경을 너무 빨리 움직이면 아무것도 보이지 않는다는 것입니다. 「임무 받기」를 누르면 닫히고, 같은 판에서는 다시 나오지 않습니다. 「처음부터 다시」로 새 판을 시작하면 다시 나옵니다.
2. **밤마다 임무 받기.** 하늘 지도 위쪽에 「첫째 밤 임무」처럼 몇째 밤인지와 임무가 나옵니다. 임무는 어느 별자리에서 천체를 몇 개(최대 세 개) 찾을지입니다. 카드를 10장 모을 때까지는 찾을 천체의 사진이 보이고, 그 뒤로는 겉모습을 쉬운 말로만 알려 줍니다. 임무 구역은 지도에서 반짝입니다. 카드를 8장 모으면 나머지 별자리 구역도 열립니다.
   - **첫 탐사 안내.** 새 판에서 첫 카드를 얻을 때까지는 한 단계씩 따라 하게 이끕니다. 하늘 지도에서는 임무 별자리 옆에 「여기를 눌러 보세요」가 뜨고, 구역 하늘에서는 화살표가 처음부터 찾을 천체 쪽을 가리킵니다. 얼룩이 시야에 들어오면 빛나는 원이 얼룩을 두르고 「이 흐릿한 얼룩이 찾는 천체예요!」라고 알려 주며, 가운데 원 안에 오면 「확대」 단추가, 확대하면 「촬영」 단추가 반짝입니다. 이 동안에는 밤 시간이 가지 않습니다. 첫 카드를 얻으면 안내는 사라지고 그때부터 밤 시간이 갑니다. 다음 훑기를 시작할 때 「이제부터 왼쪽 「찾을 천체」를 보고 스스로 찾아보세요.」가 화면 가운데에 한 번 뜹니다.
3. **길잡이 별 따라 훑기.** 별자리를 눌러 구역으로 들어가면 하늘을 손가락으로 천천히 끌어 훑습니다. 별자리의 밝은 별이 길잡이이고, 찾을 천체가 그 별에서 어느 쪽으로 얼마나 떨어져 있는지 글로 알려 줍니다. 너무 빠르게 움직이면 시야가 흐려져 아무것도 보이지 않습니다. 얼룩이 시야 가운데 가까이 오면 「확대」를 누릅니다.
4. **촬영하기.** 확대한 화면에서는 초점 눈금이 혼자 좌우로 오갑니다(1.5초에 한쪽 끝에서 다른 끝까지). 사진이 가장 또렷해지는 순간에 「촬영」을 누르면 카드를 얻습니다. 초점이 잘 맞았으면 별 3개, 조금 흐리면 2개, 흐리면 1개가 붙습니다. 너무 어긋났으면 「다시 촬영해 보아요.」가 나오고 잠깐 뒤 눈금이 다시 움직입니다. 다시 찍는 데 횟수 제한이나 감점은 없습니다.
5. **밤과 낮.** 임무마다 밤 시간이 있고, 화면의 시간 막대가 줄어듭니다(20초에 찾을 천체 하나당 50초를 더한 시간). 시간이 다 되면 망원경 속 하늘이 해돋이 빛으로 물들었다가 밝은 낮이 되고, 해넘이 빛을 거쳐 다시 어두워집니다. 낮에는 관측할 수 없어서 그동안(약 6초) 기다립니다. 다시 밤이 되면 같은 자리에서 이어 찾습니다. 초점을 맞추는 중에 시간이 다 되어도 그 촬영은 마칠 수 있습니다. 해가 뜨기 전에 임무를 다 마치면 「동트기 전 완료」 보너스를 받고, 다음 임무(다음 밤)를 받습니다. 새로 고침해도 임무와 남은 밤 시간이 이어집니다(남은 시간은 최대 5초 정도 되돌아갈 수 있습니다).
6. **묶기.** 필수 카드 20장을 모으면 사진만 보고 생김새가 비슷한 카드끼리 묶습니다. 먼저 「구름 같은 것 / 별 무리」로 나누고, 이어서 성운(방출·반사·암흑)과 성단(산개·구상)을 나눕니다. 「판정」을 누르면 맞았는지 알려 줍니다. 처음 틀리면 몇 장이 어긋났는지만 알려 주며 다시 살펴보게 하고, 또 틀리면 그때부터 어긋난 카드 몇 장에 노란 테두리가 생깁니다.
7. **도감 등록.** 묶은 카드를 한 장씩 도감에 올립니다. 이름, 별자리, 지구에서의 거리(광년)를 봅니다.
8. **결과.** 점수와 등급이 나옵니다. 점수 내역에는 카드 발견, 촬영 별점(별 1개를 넘는 별마다 25점), 동트기 전 완료(한 번에 50점), 묶기, 다섯 종류 등록, 20장 완성이 있습니다. 등급은 총점이 5600점 이상이면 수석 연구원, 4200점 이상이면 정식 연구원, 그 아래는 수습 연구원입니다. 여기서 「사진 출처」 화면을 열 수 있고, 「보너스 관측」으로 우리은하 밖의 은하와 용어 의뢰를 더 해 볼 수 있습니다. 보너스는 점수에 영향을 주지 않고, 시작 브리핑도 나오지 않습니다.

학생에게 보이는 용어는 교과서 표기를 씁니다: 우리은하, 오리온대성운, 플레이아데스성단, 말머리성운, 방출 성운, 반사 성운, 암흑 성운, 산개 성단, 구상 성단.

## 실행

컴퓨터에 Node.js가 설치되어 있어야 합니다. 아래 명령은 이 폴더(`galaxy-scope`)에서 연 터미널에 한 줄씩 입력합니다.

```
npm install
npm run dev        # http://localhost:5173/
npm test           # vitest
npm run build      # dist/ (게임 index.html, 교사 안내 teacher.html, 수업 슬라이드 lesson.html)
npm run preview    # 만들어진 dist/를 열어 확인
```

`npm run dev -- --host`로 띄우면 같은 Wi-Fi의 태블릿에서 `Network:` 주소로 열 수 있습니다.
빌드는 상대 경로(`base: './'`)를 쓰므로 `dist/`를 어느 정적 호스팅에 올려도 사진과 그림을 찾습니다.

## 사진 출처 원칙

관측 사진은 실제 천문 관측 사진만 씁니다. AI로 만든 이미지를 관측 사진으로 쓰지 않습니다.
사진마다 원문 페이지 주소, 크레딧, 라이선스, 확인한 날짜를 `src/data/objects.js`에 적습니다.
지금 사진은 ESO, NOIRLab, ESA/Hubble에서 가져온 것이고 라이선스는 CC BY 4.0입니다. 교실 기기에서 빨리 열리도록 긴 변 1024px 이하(JPEG 품질 78)로 줄였고, 화면에서는 카드 창에 맞게 잘라 보입니다. 줄이고 잘랐다는 사실도 함께 적혀 있습니다.
이 정보는 게임 안의 「사진 출처」 화면(결과 화면의 단추)에 그대로 나오고, 불러오기 화면과 하늘 지도에는 기관과 라이선스를 한 줄로 보입니다.

사진을 추가하거나 바꾸려면:

1. `src/data/objects.js`의 목록에 천체를 추가하거나, 기존 항목의 출처 주소(`sourceUrl`, `pageUrl`)와 크레딧을 원문 페이지를 보고 고칩니다.
2. `node tools/fetch-photos.mjs`를 실행합니다. 목록의 사진을 내려받아 `public/photos/<id>.jpg`로 줄여 저장합니다. 이미 있는 파일은 건너뛰므로, 사진을 바꿀 때는 먼저 그 파일을 지웁니다.

## 게임 그림 만들기

배경, 틀, 요원, 단추 같은 게임 그림은 OpenAI 이미지 생성 API로 만듭니다. 직접 그린 도형으로 대신하지 않습니다.
무엇을 만들지는 `tools/art-manifest.json`에 적혀 있고, 아래 명령으로 만듭니다.

```
node --env-file=.env tools/gen-art.mjs [파일이름 ...] [--force]
```

- 결과는 `public/art/`에 저장되고, 이미 있는 파일은 `--force` 없이는 건너뜁니다.
- API 키(`OPENAI_API_KEY`)와 모델 이름(`OPENAI_IMAGE_MODEL`)은 `.env`에만 둡니다. `.env`는 `.gitignore`에 들어 있고, 절대 커밋하지 않습니다.
- `.env`는 이 도구만 읽습니다. 게임 코드(`src/`)는 키를 쓰지 않고, 빌드한 `dist/`에도 키가 들어 있지 않습니다. `dist/`의 파일에서 `OPENAI`, `sk-`, `api.openai.com`을 찾아봐도 하나도 나오지 않습니다.
- 게임 실행과 배포에는 `.env`가 필요 없습니다.

## 배경 음악

음악 파일은 `public/audio/`에 있습니다(Lyria로 만든 곡). 첫 화면에서 「관측 시작하기」를 누를 때 켜지고, 장면에 따라 바뀝니다.

| 파일 | 나오는 곳 |
|---|---|
| `theme.mp3` | 하늘 지도 |
| `scan.mp3` | 구역 훑기와 촬영 |
| `sort.mp3` | 묶기와 도감 등록 |
| `result.mp3` | 결과 화면(한 번 나온 뒤 `theme.mp3`로 넘어갑니다) |

- 화면 오른쪽 위의 음표 단추로 켜고 끕니다. 꺼 둔 것은 그 기기 브라우저에 기억됩니다(키 `galaxy-archive-bgm`).
- 단추는 게임 화면을 가리지 않습니다. 화면 옆이나 위에 남는 띠가 있으면 거기에 놓이고, 화면이 16:9에 가까워 남는 띠가 없으면 게임이 조금 줄어 오른쪽에 단추 자리가 생깁니다.
- 곡을 바꾸려면 같은 이름의 파일로 바꿔 넣습니다. 장면과 곡의 짝은 `src/audio/bgm.js`에 있습니다.
- 곡마다 멈춘 자리를 기억해 그 장면으로 돌아오면 이어서 나옵니다. 탭을 떠나면 멈춥니다.
- 아이폰·아이패드는 웹 페이지가 볼륨을 바꿀 수 없어, 곡이 바뀔 때 서서히 줄어드는 효과 없이 바로 바뀝니다.

## 진행 상황 저장

진행 상황(찾은 카드, 현재 단계, 임무와 밤 시간, 별점, 묶기 배치, 틀린 횟수)은 그 기기 브라우저의 `localStorage`에만 저장됩니다(키 `galaxy-archive-save-v1`).
서버로 보내지 않으므로 다른 기기나 다른 브라우저에서는 이어지지 않고, 브라우저의 사이트 데이터를 지우면 사라집니다.
결과 화면의 「처음부터 다시」를 두 번 누르면 저장이 지워지고 새 판이 시작됩니다.
